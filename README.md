# 오늘의 표정 노트

브라우저에서 카메라를 사용해 얼굴 표정 추정 결과를 기록하고, 오늘의 분포와 시간대별 흐름을 확인하는 정적 웹 앱입니다.

## 실행 방법

카메라 권한은 보안 연결(HTTPS) 또는 `localhost`에서만 사용할 수 있습니다. 프로젝트 폴더를 VS Code의 Live Server 같은 정적 파일 서버로 열고 브라우저에서 접속하세요. `index.html`을 `file://`로 직접 여는 방식은 카메라가 동작하지 않을 수 있습니다.

앱 실행 중 face-api.js와 표정 인식 모델을 CDN에서 내려받으므로 최초 실행에는 인터넷 연결이 필요합니다. 서버나 Python 백엔드는 사용하지 않습니다.

## 사용 방법

1. **카메라 시작하기**를 누르고 브라우저의 카메라 권한 요청을 허용합니다.
2. 얼굴이 화면에 보이면 표정 추정 결과를 3초마다 기록합니다. **지금 기록하기**로 즉시 한 번 더 기록할 수도 있습니다.
3. **기록 멈추기**를 누르면 카메라가 종료됩니다. 오늘의 요약과 시간별 흐름은 화면에 계속 표시됩니다.
4. **오늘 기록 지우기**로 현재 날짜의 기록을 삭제할 수 있습니다.

## 개인정보와 해석 안내

카메라 영상은 브라우저 안에서만 분석하며 업로드하지 않습니다. 기록은 브라우저의 `localStorage`에 날짜별로 저장되고 이 기기의 브라우저에서만 볼 수 있습니다. 브라우저 저장 공간을 지우면 기록도 삭제됩니다.

표정 모델의 결과는 얼굴에서 관찰한 표정의 추정치일 뿐, 실제 감정이나 정신 건강을 확정하거나 진단하지 않습니다. 개인의 실제 기분과 다를 수 있으므로 참고용으로만 사용하세요.
